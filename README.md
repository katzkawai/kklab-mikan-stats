# なぜみかんの収穫量は激減したのか？

農林水産省「作物統計」の長期データ（1960年〜2024年）から見る推移と構造的要因の可視化Webサイトです。

## 公開サイト（GitHub Pages）
- URL: https://katzkawai.github.io/kklab-mikan-stats/

## 概要
- ピーク時収穫量（1975年）：3,461千トン
- 直近収穫量（2024年）：559.6千トン（ピーク比 -83.8%）
- Chart.js による主要果実（みかん・りんご・日本なし・ぶどう）の収穫量年次推移インタラクティブグラフ
- 収穫量推移の4つの歴史的フェーズと激減の4つの構造的要因の解説
